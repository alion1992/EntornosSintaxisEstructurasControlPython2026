UD1. Estructuras de datos y gestión de información en Python

Introducción

En la unidad anterior hemos aprendido a construir programas utilizando estructuras secuenciales, condicionales y repetitivas. Ya sabemos controlar el flujo de ejecución de un programa y resolver problemas mediante instrucciones.

En esta unidad daremos un paso más: aprenderemos a almacenar, organizar, consultar y modificar información.

Para ello utilizaremos ejemplos relacionados con el deporte: plantillas de equipos, resultados de competiciones, marcas de atletas, registros de entrenamiento y clasificaciones.

El recorrido de la unidad será progresivo:

  1. Primero aprenderemos a trabajar con listas y matrices.
  2. Después veremos cómo controlar errores y cómo guardar información en ficheros.
  3. A continuación estudiaremos los diccionarios.
  4. Finalmente conoceremos las tuplas y los conjuntos.

Objetivos de aprendizaje

Al finalizar esta unidad serás capaz de:

  • Crear, recorrer y modificar listas.
  • Utilizar listas para almacenar información deportiva.
  • Representar datos mediante listas bidimensionales o matrices.
  • Gestionar errores y excepciones durante la ejecución.
  • Leer y escribir información en ficheros de texto y CSV.
  • Guardar y recuperar información para que permanezca entre ejecuciones.
  • Organizar registros mediante diccionarios.
  • Diferenciar listas, diccionarios, tuplas y conjuntos.
  • Desarrollar una aplicación sencilla que gestione información deportiva.

1. Listas

1.1. ¿Qué es una lista?

Una lista es una estructura de datos que permite almacenar varios elementos dentro de una única variable.

Hasta ahora hemos utilizado variables individuales:

deportista = "Carlos"
edad = 24

Pero, ¿qué ocurre si queremos almacenar los nombres de todos los integrantes de un equipo? Podríamos crear una variable para cada deportista, pero sería poco práctico.

Para estos casos utilizamos una lista:

deportistas = ["Carlos", "Lucía", "Marcos", "Sara"]

print(deportistas)

Las listas se definen utilizando corchetes [] y separando sus elementos mediante comas.

Características de las listas

  • Ordenadas: mantienen el orden de sus elementos.
  • Modificables: podemos añadir, cambiar y eliminar elementos.
  • Permiten duplicados: un mismo valor puede aparecer varias veces.
  • Admiten distintos tipos de datos: una lista puede mezclar cadenas, números, valores booleanos e incluso otras listas.

Por ejemplo:

datos_deportista = ["Carlos", 24, 1.82, True]

print(datos_deportista)

Aunque Python permite mezclar tipos, normalmente conviene que una lista represente una colección de elementos con una finalidad común. Más adelante veremos que los diccionarios son especialmente útiles para agrupar los diferentes datos de un mismo deportista.

1.2. Acceder a los elementos

Cada elemento de una lista tiene una posición denominada índice. En Python, los índices comienzan en cero.

deportistas = ["Carlos", "Lucía", "Marcos", "Sara"]

print(deportistas[0])  # Carlos
print(deportistas[1])  # Lucía
print(deportistas[3])  # Sara

También podemos utilizar índices negativos para acceder desde el final:

print(deportistas[-1])  # Sara
print(deportistas[-2])  # Marcos

Si intentamos acceder a una posición que no existe, Python generará un error IndexError.

1.3. Modificar elementos

Las listas son mutables, por lo que podemos cambiar sus elementos después de crearlas.

deportistas = ["Carlos", "Lucía", "Marcos"]

deportistas[1] = "Elena"

print(deportistas)

Resultado:

['Carlos', 'Elena', 'Marcos']

1.4. Añadir elementos

Podemos añadir elementos utilizando diferentes métodos.

append(): añade un elemento al final de la lista.

deportistas = ["Carlos", "Lucía"]

deportistas.append("Marcos")

print(deportistas)

insert(): inserta un elemento en una posición concreta.

deportistas.insert(1, "Elena")

extend(): añade los elementos de otra colección.

deportistas.extend(["Mario", "Paula"])

1.5. Eliminar elementos

Existen diferentes formas de eliminar elementos.

remove(): elimina la primera aparición del valor indicado.

deportistas.remove("Lucía")

pop(): elimina y devuelve el elemento de una posición. Si no indicamos posición, elimina el último.

deportista_eliminado = deportistas.pop()

print("Deportista eliminado:", deportista_eliminado)

del: elimina un elemento o un rango de posiciones.

del deportistas[0]

clear(): elimina todos los elementos.

deportistas.clear()

1.6. Recorrer una lista

Podemos utilizar un bucle for para recorrer todos sus elementos:

deportistas = ["Carlos", "Lucía", "Marcos", "Sara"]

for deportista in deportistas:
    print(deportista)

Si necesitamos conocer también la posición, podemos utilizar enumerate():

for posicion, deportista in enumerate(deportistas):
    print(posicion, deportista)

También podemos recorrer una lista mediante un bucle while:

i = 0

while i < len(deportistas):
    print(deportistas[i])
    i += 1

1.7. Longitud y comprobaciones

La función len() devuelve el número de elementos de una lista:

marcas = [12.4, 11.9, 12.1, 11.8]

print("Número de marcas:", len(marcas))

Podemos comprobar si un elemento está dentro de una lista mediante in:

if "Carlos" in deportistas:
    print("El deportista está en la plantilla")

1.8. Ordenar listas

El método sort() ordena la propia lista:

marcas = [12.4, 11.9, 12.1, 11.8]

marcas.sort()

print(marcas)

Para ordenar de mayor a menor:

marcas.sort(reverse=True)

La función sorted() devuelve una nueva lista ordenada, sin modificar la original:

marcas = [12.4, 11.9, 12.1, 11.8]

marcas_ordenadas = sorted(marcas)

print(marcas_ordenadas)

1.9. Copiar listas

Hay que tener cuidado al copiar listas.

titulares = ["Carlos", "Lucía", "Marcos"]

convocatoria = titulares

convocatoria.append("Sara")

print(titulares)

En este caso, ambas variables hacen referencia a la misma lista. Para crear una copia independiente podemos utilizar:

convocatoria = titulares.copy()

También podemos utilizar list(titulares).

1.10. Funciones y métodos habituales

Una función se invoca indicando su nombre y los argumentos necesarios. Un método se invoca sobre un objeto utilizando un punto.

Algunas funciones incorporadas de Python:

Función Utilidad

len() Devuelve el número de elementos.

type() Indica el tipo de un objeto.

max() Devuelve el valor máximo.

min() Devuelve el valor mínimo.

sum() Suma los elementos de una colección numérica.

sorted() Devuelve una nueva lista ordenada.

enumerate() Permite obtener índice y valor al recorrer una colección.

round() Redondea un número.

Ejemplo:

marcas = [12.4, 11.9, 12.1, 11.8]

print("Número de marcas:", len(marcas))
print("Mejor marca:", min(marcas))
print("Peor marca:", max(marcas))
print("Suma de marcas:", sum(marcas))

En este ejemplo, si las marcas representan tiempos de una carrera, un tiempo menor es mejor.

Algunos métodos habituales de las listas:

Método Utilidad

append() Añade un elemento al final. insert() Inserta un elemento en una posición. extend() Añade varios elementos. remove() Elimina la primera aparición de un valor. pop() Elimina y devuelve un elemento. clear() Vacía la lista. index() Devuelve la posición de un elemento. count() Cuenta las apariciones de un elemento. sort() Ordena la lista original. reverse() Invierte el orden de la lista. copy() Crea una copia superficial.

1.11. Listas bidimensionales o matrices

Una matriz es una estructura que organiza la información en filas y columnas.

En Python podemos representar una matriz mediante una lista que contiene otras listas. También se conoce como lista bidimensional.

Por ejemplo, podemos representar los puntos conseguidos por un equipo en cuatro jornadas:

puntos = [
    [3, 1, 3, 0],
    [1, 1, 3, 3],
    [0, 3, 1, 3]
]

Cada fila puede representar un equipo y cada columna una jornada.

Equipo Jornada 1 Jornada 2 Jornada 3 Jornada 4

Equipo A 3 1 3 0 Equipo B 1 1 3 3 Equipo C 0 3 1 3

Acceder a los elementos

Para acceder a un elemento necesitamos indicar dos índices:

  • El primero representa la fila.
  • El segundo representa la columna.
print(puntos[0][0])  # 3
print(puntos[1][2])  # 3
print(puntos[2][1])  # 3

Recorrer una matriz

Necesitamos dos bucles: uno para recorrer las filas y otro para recorrer los elementos de cada fila.

for fila in puntos:
    for puntuacion in fila:
        print(puntuacion, end=" ")
    print()

Conocer las dimensiones

Podemos utilizar len() para conocer el número de filas y columnas:

filas = len(puntos)
columnas = len(puntos[0])

print("Filas:", filas)
print("Columnas:", columnas)

Esta forma presupone que la matriz tiene al menos una fila y que todas las filas tienen el mismo número de elementos.

Modificar elementos

puntos[0][1] = 3

Recorrer una matriz mediante índices

for i in range(len(puntos)):
    for j in range(len(puntos[i])):
        print(f"Fila {i}, columna {j}: {puntos[i][j]}")

Crear una matriz

Podemos crear una matriz vacía e incorporar filas:

matriz = []

for i in range(3):
    fila = []
    for j in range(4):
        fila.append(0)
    matriz.append(fila)

print(matriz)

También podemos utilizar una comprensión de listas:

matriz = [[0 for j in range(4)] for i in range(3)]

Es importante evitar crear matrices de esta forma:

# No recomendado
matriz = [[0] * 4] * 3

En este último caso, las filas hacen referencia a la misma lista interna y modificar una posición puede afectar a varias filas.

2. Control de errores y excepciones

2.1. ¿Qué es una excepción?

Una excepción es un error que se produce durante la ejecución de un programa y que puede interrumpir su funcionamiento si no se gestiona.

Por ejemplo:

edad = int(input("Introduce la edad del deportista: "))

Si el usuario introduce un texto en lugar de un número, Python generará una excepción ValueError.

Para evitar que el programa termine inesperadamente, podemos controlar las excepciones.

2.2. try y except

Podemos controlar los errores mediante try y except:

try:
    edad = int(input("Introduce la edad del deportista: "))
    print("Edad:", edad)

except ValueError:
    print("Debes introducir una edad válida")

El código que puede generar una excepción se introduce dentro de try. Si se produce el error indicado, se ejecuta el bloque except.

2.3. Controlar varias excepciones

Podemos utilizar diferentes bloques except:

try:
    dorsal = int(input("Introduce el dorsal: "))
    resultado = 100 / dorsal
    print(resultado)

except ValueError:
    print("El dorsal debe ser un número entero")

except ZeroDivisionError:
    print("El dorsal no puede ser cero")

También podemos agrupar excepciones cuando queremos darles el mismo tratamiento:

except (ValueError, ZeroDivisionError):
    print("Se ha producido un error en la operación")

2.4. La excepción padre Exception

Exception es la clase base de la mayoría de las excepciones habituales que se producen durante la ejecución.

Podemos utilizarla para capturar otros errores no contemplados anteriormente:

try:
    dorsal = int(input("Introduce el dorsal: "))
    resultado = 100 / dorsal
    print(resultado)

except ValueError:
    print("El dorsal debe ser un número")

except ZeroDivisionError:
    print("No se puede dividir entre cero")

except Exception as error:
    print("Se ha producido un error:", error)

Importante: los bloques más específicos deben aparecer antes que los más generales. Si colocamos except Exception al principio, capturará también las excepciones que podrían haber sido tratadas por los bloques posteriores.

2.5. else y finally

El bloque else se ejecuta cuando el bloque try termina sin producir ninguna excepción.

El bloque finally se ejecuta tanto si se produce una excepción como si no.

try:
    edad = int(input("Introduce la edad del deportista: "))

except ValueError:
    print("Debes introducir un número entero")

else:
    print("Edad registrada:", edad)

finally:
    print("Operación finalizada")

2.6. Excepciones habituales

Excepción Cuándo puede producirse

ValueError Cuando un valor tiene un formato incorrecto para una operación.

TypeError Cuando se utiliza un tipo de dato incompatible.

IndexError Cuando se accede a una posición inexistente de una lista.

KeyError Cuando se consulta una clave inexistente de un diccionario.

ZeroDivisionError Cuando se divide entre cero.

FileNotFoundError Cuando no se encuentra un fichero.

PermissionError Cuando no se tienen permisos para acceder a un recurso.

Exception Clase base para capturar excepciones generales.

3. Ficheros en Python

3.1. ¿Por qué necesitamos ficheros?

Hasta ahora hemos almacenado la información en variables y estructuras de datos. El problema es que esos datos desaparecen cuando finaliza el programa.

Los ficheros permiten almacenar información de forma permanente para recuperarla posteriormente.

Por ejemplo, una aplicación de gestión de un club deportivo necesita guardar los datos de sus deportistas para que sigan disponibles cuando volvamos a ejecutar el programa.

3.2. Abrir un fichero

Python proporciona la función open() para trabajar con ficheros:

fichero = open("deportistas.txt", "r", encoding="utf-8")

Sus principales argumentos son:

  • Nombre o ruta del fichero.
  • Modo de apertura.
  • Codificación, cuando trabajamos con texto.

3.3. Modos de apertura

Modo Descripción

r Lectura. El fichero debe existir. w Escritura. Crea el fichero o sobrescribe su contenido. a Añadir información al final del fichero. x Crea un fichero nuevo. Falla si ya existe. b Modo binario. Se combina con otros modos. t Modo texto, predeterminado. + Permite lectura y escritura. Se combina con otros modos.

Importante: el modo w elimina el contenido anterior del fichero si ya existe.

3.4. Escribir en un fichero

Podemos utilizar write() para escribir texto:

fichero = open("deportistas.txt", "w", encoding="utf-8")

fichero.write("Carlos - Atletismo\n")
fichero.write("Lucía - Natación\n")
fichero.write("Marcos - Ciclismo\n")

fichero.close()

El carácter \n introduce un salto de línea.

3.5. Añadir información

Si queremos conservar el contenido anterior y añadir información al final, utilizamos el modo a:

fichero = open("deportistas.txt", "a", encoding="utf-8")

fichero.write("Sara - Baloncesto\n")

fichero.close()

3.6. Leer un fichero

Podemos leer todo el contenido con read():

fichero = open("deportistas.txt", "r", encoding="utf-8")

contenido = fichero.read()

print(contenido)

fichero.close()

También podemos leer una línea con readline():

fichero = open("deportistas.txt", "r", encoding="utf-8")

linea = fichero.readline()

print(linea)

fichero.close()

O todas las líneas mediante readlines():

fichero = open("deportistas.txt", "r", encoding="utf-8")

lineas = fichero.readlines()

print(lineas)

fichero.close()

3.7. Utilizar with

La forma recomendada de trabajar con ficheros es utilizar with.

Esta estructura se encarga de cerrar el fichero automáticamente cuando termina el bloque, incluso si se produce una excepción.

with open("deportistas.txt", "r", encoding="utf-8") as fichero:
    contenido = fichero.read()
    print(contenido)

Para escribir:

with open("deportistas.txt", "w", encoding="utf-8") as fichero:
    fichero.write("Carlos - Atletismo\n")
    fichero.write("Lucía - Natación\n")

3.8. Recorrer un fichero línea a línea

Podemos recorrer directamente el objeto fichero:

with open("deportistas.txt", "r", encoding="utf-8") as fichero:
    for linea in fichero:
        print(linea.strip())

strip() elimina los caracteres de espacio y salto de línea que aparecen en los extremos.

3.9. Comprobar si existe un fichero

Podemos utilizar el módulo os:

import os

if os.path.exists("deportistas.txt"):
    print("El fichero existe")
else:
    print("El fichero no existe")

También podemos trabajar con rutas mediante pathlib:

from pathlib import Path

ruta = Path("deportistas.txt")

if ruta.exists():
    print("El fichero existe")

3.10. Trabajar con ficheros CSV

Un fichero CSV permite almacenar datos organizados en columnas, separadas normalmente por comas o punto y coma.

Ejemplo de contenido de deportistas.csv:

nombre;deporte;edad;club
Carlos;Atletismo;24;Club Norte
Lucía;Natación;22;Club Acuático
Marcos;Ciclismo;27;Pedal Team

Python proporciona el módulo csv para trabajar con este formato.

Leer un CSV

import csv

with open("deportistas.csv", "r", encoding="utf-8", newline="") as fichero:
    lector = csv.reader(fichero, delimiter=";")

    for fila in lector:
        print(fila)

Escribir un CSV

import csv

deportistas = [
    ["Carlos", "Atletismo", 24, "Club Norte"],
    ["Lucía", "Natación", 22, "Club Acuático"],
    ["Marcos", "Ciclismo", 27, "Pedal Team"]
]

with open("deportistas.csv", "w", encoding="utf-8", newline="") as fichero:
    escritor = csv.writer(fichero, delimiter=";")

    escritor.writerow(["nombre", "deporte", "edad", "club"])
    escritor.writerows(deportistas)

4. Diccionarios

4.1. ¿Qué es un diccionario?

Un diccionario permite almacenar información organizada mediante parejas de clave y valor.

A diferencia de las listas, donde accedemos a los elementos mediante índices, en los diccionarios accedemos mediante claves.

deportista = {
    "nombre": "Carlos",
    "edad": 24,
    "deporte": "Atletismo",
    "dorsal": 15
}

En este ejemplo:

  • "nombre" es una clave.
  • "Carlos" es su valor.
  • "edad" es otra clave.
  • 24 es su valor.

Las claves deben ser únicas y deben ser de tipos inmutables, como cadenas, números o tuplas.

4.2. Acceder a los valores

Podemos acceder a un valor indicando su clave:

print(deportista["nombre"])
print(deportista["deporte"])

Si intentamos acceder a una clave que no existe, obtendremos un KeyError.

Podemos utilizar get() para consultar una clave de forma segura:

print(deportista.get("club"))
print(deportista.get("club", "Sin club"))

4.3. Añadir y modificar información

Para añadir una nueva pareja o modificar una existente utilizamos la clave:

deportista["club"] = "Club Norte"
deportista["edad"] = 25

4.4. Eliminar información

Podemos utilizar del:

del deportista["dorsal"]

También podemos utilizar pop():

deporte = deportista.pop("deporte")

4.5. Recorrer un diccionario

Podemos recorrer únicamente las claves:

for clave in deportista:
    print(clave)

Recorrer los valores:

for valor in deportista.values():
    print(valor)

O recorrer claves y valores simultáneamente:

for clave, valor in deportista.items():
    print(clave, ":", valor)

4.6. Diccionarios con varios registros

Una aplicación real puede necesitar almacenar información de muchos deportistas.

Podemos utilizar una lista de diccionarios:

deportistas = [
    {"nombre": "Carlos", "deporte": "Atletismo", "marca": 10.8},
    {"nombre": "Lucía", "deporte": "Natación", "marca": 58.4},
    {"nombre": "Marcos", "deporte": "Ciclismo", "marca": 42.5}
]

for deportista in deportistas:
    print(deportista["nombre"], deportista["deporte"])

También podemos utilizar un diccionario cuyos valores sean otros diccionarios:

clubes = {
    "C001": {
        "nombre": "Club Norte",
        "deporte": "Atletismo",
        "localidad": "Puertollano"
    },
    "C002": {
        "nombre": "Club Acuático",
        "deporte": "Natación",
        "localidad": "Ciudad Real"
    }
}

print(clubes["C001"]["nombre"])

4.7. Métodos habituales de los diccionarios

Método Utilidad

keys() Devuelve las claves. values() Devuelve los valores. items() Devuelve las parejas clave-valor. get() Consulta una clave de forma segura. pop() Elimina una clave y devuelve su valor. update() Actualiza el diccionario. clear() Elimina todos los elementos.

5. Tuplas y conjuntos

5.1. Tuplas

¿Qué es una tupla?

Una tupla es una estructura de datos que permite almacenar varios elementos, igual que una lista. La diferencia principal es que una tupla es inmutable: una vez creada, no podemos modificar, añadir ni eliminar directamente sus elementos.

Las tuplas se suelen definir utilizando paréntesis:

coordenadas = (40.4168, -3.7038)
resultados = (10.8, 11.2, 10.9)

Acceder a sus elementos

Al igual que las listas, las tuplas utilizan índices que comienzan en cero:

resultados = (10.8, 11.2, 10.9)

print(resultados[0])
print(resultados[-1])

Recorrer una tupla

Podemos utilizar un bucle for:

marcas = (10.8, 11.2, 10.9)

for marca in marcas:
    print(marca)

Operaciones habituales

Podemos utilizar len(), in, count() e index():

resultados = (10.8, 11.2, 10.8, 10.9)

print(len(resultados))
print(10.8 in resultados)
print(resultados.count(10.8))
print(resultados.index(11.2))

Una tupla de un solo elemento necesita una coma:

dorsal = (15,)

¿Cuándo utilizar una tupla?

Utilizaremos una tupla cuando queramos representar un conjunto de datos que no debería modificarse.

Por ejemplo, unas coordenadas, una fecha de celebración o unos resultados que queremos conservar como referencia.

Diferencias entre listas y tuplas

Característica Lista Tupla

Sintaxis [] () Ordenada Sí Sí Modificable Sí No Permite duplicados Sí Sí Acceso por índice Sí Sí

5.2. Conjuntos (set)

¿Qué es un conjunto?

Un conjunto es una estructura de datos que almacena elementos sin duplicados y que no utiliza índices para acceder a ellos.

Se define utilizando llaves {} o mediante set():

deportes = {"Atletismo", "Natación", "Ciclismo"}

Si introducimos elementos repetidos, Python los almacena una sola vez:

deportes = {
    "Atletismo",
    "Natación",
    "Atletismo",
    "Ciclismo"
}

print(deportes)

Un conjunto vacío se crea con set(), ya que {} representa un diccionario vacío.

Añadir y eliminar elementos

deportes = {"Atletismo", "Natación"}

deportes.add("Ciclismo")
deportes.remove("Natación")

remove() genera un error si el elemento no existe. Podemos utilizar discard() para evitar ese error:

deportes.discard("Baloncesto")

Operaciones entre conjuntos

Los conjuntos permiten realizar operaciones matemáticas.

deportes_club_a = {"Atletismo", "Natación", "Ciclismo"}
deportes_club_b = {"Natación", "Baloncesto", "Ciclismo"}

Unión: elementos que aparecen en cualquiera de los dos conjuntos.

print(deportes_club_a | deportes_club_b)

Intersección: elementos comunes.

print(deportes_club_a & deportes_club_b)

Diferencia: elementos que están en el primer conjunto, pero no en el segundo.

print(deportes_club_a - deportes_club_b)

Diferencia simétrica: elementos que están en uno de los conjuntos, pero no en ambos.

print(deportes_club_a ^ deportes_club_b)

¿Cuándo utilizar conjuntos?

Son especialmente útiles cuando necesitamos eliminar duplicados o comprobar si un elemento pertenece a una colección.

deportes_practicados = [
    "Atletismo",
    "Natación",
    "Atletismo",
    "Ciclismo",
    "Natación"
]

deportes_unicos = set(deportes_practicados)

print(deportes_unicos)

6. Proyecto práctico: gestión de un club deportivo

Descripción

Vamos a desarrollar una aplicación de consola para gestionar los deportistas de un club.

La aplicación permitirá registrar deportistas, consultar la plantilla, buscar participantes, modificar sus datos y eliminarlos.

Los datos deberán almacenarse en un fichero CSV para que permanezcan disponibles cuando cerremos y volvamos a ejecutar el programa.

Menú de la aplicación

================================
      GESTIÓN CLUB DEPORTIVO
================================
1. Registrar deportista
2. Mostrar plantilla
3. Buscar deportista
4. Modificar datos
5. Eliminar deportista
6. Mostrar estadísticas
0. Salir
================================

Información de cada deportista

Cada deportista tendrá los siguientes datos:

  • DNI o identificador.
  • Nombre.
  • Edad.
  • Deporte.
  • Club o equipo.
  • Número de dorsal.

Estructura de datos

Los deportistas se almacenarán en una lista de diccionarios:

deportistas = [
    {
        "dni": "11111111A",
        "nombre": "Carlos",
        "edad": 24,
        "deporte": "Atletismo",
        "club": "Club Norte",
        "dorsal": 15
    },
    {
        "dni": "22222222B",
        "nombre": "Lucía",
        "edad": 22,
        "deporte": "Natación",
        "club": "Club Acuático",
        "dorsal": 8
    }
]

Almacenamiento

Los deportistas deberán guardarse en un fichero CSV llamado deportistas.csv.

La aplicación deberá:

  • Cargar los deportistas al iniciar.
  • Guardar los cambios realizados.
  • Evitar identificadores duplicados.
  • Controlar los errores al leer o escribir el fichero.

Funcionalidades

1. Registrar deportista

Solicitar los datos y comprobar que el identificador no existe previamente. La edad y el dorsal deberán ser valores válidos.

2. Mostrar plantilla

Mostrar todos los deportistas almacenados, indicando sus datos.

3. Buscar deportista

Permitir buscar un deportista mediante su DNI o identificador.

4. Modificar datos

Solicitar el identificador de un deportista y permitir actualizar sus datos.

5. Eliminar deportista

Eliminar un deportista a partir de su identificador.

6. Mostrar estadísticas

Mostrar:

  • Número total de deportistas.
  • Edad media de la plantilla.
  • Deportista de mayor edad.
  • Deportista de menor edad.
  • Deportes diferentes practicados en el club.

Condiciones técnicas

  • Utilizar listas y diccionarios.
  • Utilizar bucles y estructuras condicionales.
  • Utilizar métodos y funciones de Python.
  • Trabajar con ficheros CSV.
  • Gestionar las excepciones necesarias.
  • Organizar el código en funciones para evitar repetir instrucciones.
  • Comprobar que los datos introducidos por el usuario son válidos.

Ampliaciones voluntarias

  • Permitir ordenar los deportistas por edad.
  • Mostrar los deportistas de un deporte concreto.
  • Calcular la edad media por deporte.
  • Mostrar los deportes diferentes utilizando un conjunto.
  • Incorporar una opción para exportar una clasificación.
